# 04. Секрети й безпека

## Що таке секрет

Секрет — це все, що дає доступ до твоїх акаунтів:

| Секрет | Що дає |
|---|---|
| `TELEGRAM_BOT_TOKEN` | повне керування твоїм ботом |
| `NGROK_AUTHTOKEN` | використання твого акаунта ngrok |
| `CLOUDFLARE_TUNNEL_TOKEN` | запуск твого тунелю Cloudflare |
| `N8N_ENCRYPTION_KEY` | розшифрування збережених у n8n паролів |
| пароль власника n8n | вхід у твій n8n |

## Правила

1. **Секрети живуть тільки у `.env`** на твоєму Mac. Файл створює `Setup.command`.
2. **`.env` ніколи не потрапляє в git.** Він записаний у `.gitignore`.
3. **Не надсилай секрети** в чати, пошту, скріншоти, документи. На скріншотах зафарбовуй токени.
4. **Не губи `N8N_ENCRYPTION_KEY`.** Без нього n8n не прочитає збережені credentials. Зроби копію `.env` у менеджер паролів.
5. **Пароль власника n8n** має бути надійним: твій n8n доступний через тунель.

## Якщо секрет потрапив у чужі руки

Заміни його одразу:

- **Токен бота:** @BotFather → `/mybots` → бот → **API Token** → **Revoke current token**. Встав новий через `Setup.command` і в n8n (**Credentials**).
- **ngrok:** панель ngrok → **Your Authtoken** → **Reset**. Встав новий через `Setup.command`.
- **Cloudflare:** панель Cloudflare → тунель → **Refresh token**. Онови `.env`.

Після заміни: `Stop.command`, потім `Start.command`.

## Що захищає пакет автоматично

- `.gitignore` не дає закомітити `.env`.
- `tests/secrets-check.sh` шукає токени в усіх файлах, які відстежує git. `Check.command` запускає його разом з іншими перевірками.
- На GitHub кожен коміт перевіряє CI (gitleaks): якщо знайде токен, перевірка стане червоною.
- Тунель ngrok пропускає з інтернету лише адреси `/webhook/...` і `/healthz`. Сторінка входу n8n відкривається тільки на твоєму Mac.

## Для тих, хто вміє git: pre-commit перевірка

Щоб токен не потрапив навіть у локальний коміт, встанови [gitleaks](https://github.com/gitleaks/gitleaks) (`brew install gitleaks`) і в папці пакета виконай:

```bash
git config core.hooksPath .githooks
```

Тепер кожен `git commit` перевірятиметься автоматично.

## Експорт workflow

n8n не додає токени у файли експорту workflow, тож ними можна ділитися. Перед тим як надіслати файл, все одно запусти `Check.command`.
