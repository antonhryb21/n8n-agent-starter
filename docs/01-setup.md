# 01. Встановлення

Робиться один раз. Знадобиться близько 20 хвилин.

## 1. Docker Desktop

Docker запускає n8n і тунель у готових "коробках", тож тобі не треба нічого налаштовувати вручну.

1. Дізнайся свій чип:  → **About This Mac**. Рядок **Chip** (Apple M1/M2/M3/M4) означає Apple Silicon, рядок **Processor** (Intel) означає Intel.
2. Завантаж Docker Desktop для свого чипа з [docker.com](https://www.docker.com/products/docker-desktop/).
3. Відкрий завантажений файл і перетягни Docker у папку **Applications**.
4. Запусти Docker з Applications. Погодься з умовами (для навчання він безкоштовний).
5. Дочекайся внизу вікна статусу **Engine running** (зелений).

<!-- screenshot: Docker Desktop зі статусом Engine running -->

> **Mac з 8 ГБ пам'яті працює повільно?** Замість Docker Desktop можна поставити [OrbStack](https://orbstack.dev): він легший і працює з тими самими файлами пакета.

## 2. Telegram-бот

1. Відкрий у Telegram **@BotFather** (з синьою галочкою).
2. Надішли `/newbot`.
3. Введи назву бота, наприклад `Мій агент`.
4. Введи ім'я користувача, яке закінчується на `bot`, наприклад `my_agent_course_bot`.
5. BotFather надішле **токен**, рядок виду `1234567890:AA...`. Скопіюй його.

<!-- screenshot: повідомлення BotFather з токеном (токен зафарбовано) -->

> Токен схожий на пароль від бота. Нікому його не показуй. Детальніше: [04-security.md](04-security.md).

## 3. ngrok

ngrok дає твоєму n8n постійну публічну адресу, щоб Telegram міг до нього достукатись.

1. Зареєструйся на [ngrok.com](https://ngrok.com) (безкоштовно, можна через Google або GitHub).
2. У панелі ngrok відкрий **Your Authtoken** і скопіюй ключ.
3. Відкрий **Domains**. Там уже є твоя адреса виду `щось-щось.ngrok-free.app`. Скопіюй її **без** `https://`.

## 4. Завантаж пакет

1. На сторінці репозиторію на GitHub натисни **Code** → **Download ZIP**.
2. Розпакуй архів, наприклад у папку **Documents**.

(Якщо вмієш користуватися git, можеш замість цього зробити `git clone`.)

Один раз зніми з папки позначку "завантажено з інтернету", інакше macOS не дасть відкрити `.command`-файли:

1. Відкрий **Terminal** (Cmd+Пробіл → введи `Terminal` → Enter).
2. Введи `xattr -dr com.apple.quarantine ` (з пробілом наприкінці).
3. Перетягни у вікно Терміналу папку пакета і натисни Enter.

Якщо ти завантажив пакет через `git clone`, цей крок не потрібен.

## 5. Setup.command

1. Відкрий папку пакета у Finder.
2. Двічі клацни **`Setup.command`**.
   - Якщо macOS пише, що файл "не був відкритий" і пропонує лише **Перемістити в Корзину** або **Готово**: натисни **Готово** і зроби крок з розділу 4 про `xattr`.
3. Відкриється вікно Терміналу. Встав по черзі:
   - токен бота;
   - на питання про тунель просто натисни Enter (лишиться ngrok);
   - Authtoken ngrok;
   - адресу ngrok.
4. Побачиш `✅ Налаштування збережено у .env`.

Готово. Тепер перейди до [02-first-workflow.md](02-first-workflow.md).
