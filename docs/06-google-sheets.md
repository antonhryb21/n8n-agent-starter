# 06. Ліди з Google Таблиці в Telegram

Мета: кожен новий рядок у Google Таблиці (наприклад, лід, який туди записала інтеграція з Meta Lead Ads) за хвилину приходить повідомленням у Telegram.

```
Meta Lead Ads  →  Google Таблиця  →  n8n (перевіряє щохвилини)  →  повідомлення в Telegram
```

Спершу пройди [02-first-workflow.md](02-first-workflow.md): бот має відповідати на `привіт`. Близько 20 хвилин.

## Як це працює

1. Щохвилини n8n читає таблицю.
2. Нові ліди — це рядки, у яких порожній стовпець **`Telegram`**.
3. Кожен такий лід n8n надсилає в Telegram, а в стовпець `Telegram` записує час відправки. Тож кожен лід приходить один раз.

Повідомлення виглядає так:

```
🔥 Новий лід

Ім'я: Іван Петренко
Телефон: +380501112233
Email: ivan@example.com
Кампанія: Осінній розпродаж
```

У повідомлення потрапляють усі непорожні стовпці рядка. Типові стовпці Meta (`full_name`, `phone_number`, `email`, `campaign_name`, `ad_name`, `form_name` тощо) підписуються українською, технічні (`id`, `ad_id`, `form_id`...) пропускаються, а префікс `p:` перед телефоном прибирається.

## 1. Підготуй таблицю

1. Відкрий таблицю, куди приходять ліди.
2. У першому рядку, у першій вільній клітинці праворуч від заголовків, впиши **`Telegram`** (саме так, латиницею з великої літери).
3. Запам'ятай назву вкладки внизу (наприклад, `Аркуш1` або `Sheet1`).
4. Скопіюй адресу таблиці з рядка браузера: `https://docs.google.com/spreadsheets/d/1AbC.../edit`.

**Старі ліди.** Без додаткових дій n8n надішле всі рядки, які вже є в таблиці. Якщо їх не треба надсилати, запиши номер першого рядка, з якого починаються нові ліди (наприклад, `158`). Він знадобиться на кроці 5.

## 2. Створи сервісний акаунт Google

Сервісний акаунт — це окремий "робот-користувач" Google, від імені якого n8n читає таблицю. Він не потребує входу через браузер і не "вилітає" щотижня.

Використовуй **особистий акаунт Gmail**: у робочих акаунтах адміністратор часто забороняє створювати ключі.

1. Відкрий [console.cloud.google.com](https://console.cloud.google.com) і погодься з умовами, якщо попросить.
2. Вгорі натисни на вибір проєкту → **New Project** → назва `n8n-bot` → **Create**. Переконайся, що вгорі обрано саме цей проєкт.
3. Відкрий [Google Sheets API](https://console.cloud.google.com/apis/library/sheets.googleapis.com) → **Enable**.
4. Відкрий [Google Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com) → **Enable**.
5. Відкрий [Service Accounts](https://console.cloud.google.com/iam-admin/serviceaccounts) → **Create service account** → назва `n8n-sheets` → **Create and continue** → **Done** (ролі не потрібні).
6. Клацни на створений акаунт → вкладка **Keys** → **Add key** → **Create new key** → **JSON** → **Create**.

Браузер завантажить файл `n8n-bot-....json`. **Це секрет.** Не клади його в папку пакета і нікому не надсилай. Після кроку 4 його можна видалити.

## 3. Дай роботу доступ до таблиці

1. Відкрий завантажений JSON-файл у TextEdit.
2. Знайди рядок `"client_email"` і скопіюй адресу в лапках. Вона закінчується на `iam.gserviceaccount.com`.
3. У таблиці лідів натисни **Share** (Надати доступ), встав цю адресу, обери роль **Editor** (Редактор), зніми галочку **Notify people** → **Share**.

Роль **Editor** потрібна, бо n8n записує час відправки в стовпець `Telegram`. Інші стовпці він не змінює.

## 4. Імпортуй workflow і підключи credentials

1. У n8n: **Create Workflow** → меню **⋯** → **Import from File** → `workflows/sheets-leads-to-telegram.json`.
2. Двічі клацни вузол **Прочитати таблицю** → **Credential to connect with** → **Create New Credential** (тип **Google Service Account API**):
   - **Service Account Email**: адреса `client_email` з JSON-файлу;
   - **Private Key**: значення `"private_key"` з JSON-файлу, від `-----BEGIN` до `-----END PRIVATE KEY-----\n` включно, без лапок;
   - **Save**. n8n зашифрує ключ і зберігає його у себе.
3. Відкрий вузол **Позначити надісланим** і обери той самий Google-credential.
4. Відкрий вузли **Повідомлення боту**, **Надіслати в Telegram** і **Відповісти chat ID** і обери credential бота, який ти створив у [02-first-workflow.md](02-first-workflow.md).

## 5. Заповни налаштування

Двічі клацни вузол **Налаштування** і заміни значення:

| Поле | Що вписати |
|---|---|
| `sheetUrl` | адреса таблиці з кроку 1 |
| `sheetName` | назва вкладки з кроку 1 |
| `chatId` | поки залиш як є, заповниш на кроці 6 |
| `startRow` | `2`, щоб надіслати всі ліди, або номер першого нового рядка з кроку 1 |

## 6. Увімкни workflow і дізнайся chat ID

У одного бота може бути лише одна адреса webhook, тож активним має бути **лише один** workflow з цим ботом.

1. Відкрий workflow **Telegram Echo** і перемкни **Active → Inactive**.
2. Повернись у **Ліди з Google Таблиці → Telegram**, натисни **Save** і перемкни **Inactive → Active**.
3. Напиши боту будь-що. Він відповість: `Chat ID цього чату: 123456789`.
4. Впиши це число в поле `chatId` вузла **Налаштування** → **Save**.

**Хочеш отримувати ліди в групу?** Додай бота в групу і напиши там `/start@назва_твого_бота`. Бот відповість ID групи (воно починається з `-`). Впиши його в `chatId`.

## 7. Перевір

1. Додай у таблицю тестовий рядок вручну (наприклад, ім'я й телефон), стовпець `Telegram` залиш порожнім.
2. Протягом хвилини в Telegram має прийти `🔥 Новий лід`, а в стовпці `Telegram` з'явиться час.
3. Тестовий рядок можна видалити.

## Якщо не працює

Відкрий у n8n вкладку **Executions** цього workflow. Успішні перевірки там не зберігаються (щоб не захаращувати n8n), тож ти побачиш лише запуски з помилкою. Клацни останній і подивись, на якому вузлі червона помилка.

| Помилка | Причина | Що робити |
|---|---|---|
| `The caller does not have permission` або `403` | таблицю не поширено на сервісний акаунт | крок 3 |
| `Requested entity was not found` або `404` | неправильна адреса таблиці | скопіюй адресу ще раз у **Налаштування** |
| `Sheet with name "..." not found` | інша назва вкладки | виправ `sheetName` |
| `Google Sheets API has not been used in project` | API не ввімкнено | крок 2, пункти 3–4, і зачекай 2–3 хвилини |
| `error:1E08010C` або `invalid_grant` у credential | ключ вставлено не повністю | встав `private_key` ще раз, від `-----BEGIN` до кінця |
| помилка про стовпець `Telegram` у вузлі **Позначити надісланим** | у таблиці немає стовпця `Telegram` | крок 1, пункт 2 |
| `Bad Request: chat not found` у **Надіслати в Telegram** | неправильний `chatId` або ти ще не писав боту | крок 6, пункти 3–4 |
| один лід приходить знову й знову | n8n не може записати в стовпець `Telegram` | дай роботу роль **Editor** (крок 3) |

Ліди приходять пачками по 20? Так задумано: якщо нових рядків багато, n8n надсилає 20 за хвилину, щоб Telegram не заблокував бота за спам.

Бот не відповідає на крок 6 і в **Executions** нічого немає? Запусти `Check.command` і подивись [03-troubleshooting.md](03-troubleshooting.md). Надсилання лідів працює і без тунелю, а відповідь з chat ID — лише з ним.

## Безпека

- **JSON-ключ сервісного акаунта** дає доступ до всіх таблиць, якими ти з ним поділився. Він зберігається лише в n8n (зашифрованим за допомогою `N8N_ENCRYPTION_KEY`), не в `.env` і не в git. Сам файл після налаштування видали.
- Якщо ключ потрапив у чужі руки: [Service Accounts](https://console.cloud.google.com/iam-admin/serviceaccounts) → акаунт → **Keys** → видали ключ, створи новий і встав його в n8n (**Credentials**).
- Ліди містять персональні дані (імена, телефони). Надсилай їх лише в особистий чат або закриту групу, де є тільки ті, кому вони потрібні.
- Бот відповідає chat ID будь-кому, хто йому напише, але ліди отримує лише чат, вписаний у `chatId`.
